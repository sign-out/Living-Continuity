# Living Continuity — Voyage source synchronization (2026-11-03)

**Tag:** `v2026.11.03` | **Format:** Voyage V37 | **Channel:** GitHub source-synchronized release

## Included
- `Living_Continuity.json` — **recommended installable modular LC**. Preserves the October 2026 Voyage compatibility layer and its combat-focused `generateNPCIntents` routing.
- `addons/LC_Groups_That_Remember.json` — standalone Groups That Remember add-on.
- `addons/LC_SkillWeave.json` — standalone SkillWeave add-on.
- `exports/LC_Voyage_2026-11-03.json` — normalized JSON snapshot of the supplied current Voyage export, for traceability; not the recommended installation file.

## Changes and verification
- Compared the supplied Voyage export against `main`: **204 native trigger definitions are semantically identical**, including 196 nonempty JavaScript scripts. No trigger, command, storage key, or feature is claimed to have changed in this release.
- The supplied export includes native `itemSettings` tiers and an empty `parties[""].entities` map; those are host-export data, **not an LC engine upgrade**. To avoid imposing those values on an unrelated host world, they are retained in the dated source snapshot rather than automatically overlaid on the installable modular core.
- The source export omits compatibility instructions already present on `main`. The installable file deliberately preserves them: native result precedence, discovered-world visibility, conditional starts, actor identity, committed-effect handling, and combat-only NPC intent routing.
- Inspected the bundled “Groups That Remember” Voyage export. It is an entire LC+Groups world, **not** the six-trigger standalone add-on. Its two group-script differences remove defensive optional-source handling and flexible group command parsing, so they were **not** promoted into the standalone distribution. A separate bundled core trigger also failed static JavaScript parsing. The existing standalone add-on remains intact.
- Static script parsing: supplied modular LC export **196/196** scripts parse; the separately supplied full bundled Groups export contains an unrelated core parse failure and is intentionally not packaged.
- No in-game Voyage runtime validation has been claimed. Validate with the current Studio importer and test combat, OOC commands, clock, groups, and host-state precedence in a host world before production deployment.
