# Living Continuity — Groups bundled export syntax fix

**Patch release:** `v2026.11.03.1` · **Voyage format:** V37 · **Scope:** archival source correction; no change to the recommended modular installables.

## Fixed

The previously supplied *full LC + Groups That Remember* Voyage export contained malformed JavaScript in `sys_lc_quest_summary_command`. The message text had an unescaped apostrophe in `world's`, which prevented the script from compiling. The newly supplied corrected export escapes that apostrophe. Compared with the previous bundled export, this **one script string is the only changed JSON value**.

The corrected full export is now archived at `exports/LC_Groups_Bundled_Quest_Summary_Fixed_2026-11-03.json` and attached to this GitHub release. The earlier rejected bundle was not distributed in the previous GitHub release, and the original `v2026.11.03` release remains immutable.

## What is included

- `Living_Continuity.json` — unchanged **recommended** host-safe modular core.
- `LC_Groups_That_Remember.json` — unchanged standalone six-trigger Groups add-on.
- `LC_SkillWeave.json` — unchanged standalone SkillWeave add-on.
- `LC_Groups_Bundled_Quest_Summary_Fixed_2026-11-03.json` — **corrected full bundled Voyage export for reference and reproducibility**, not another standalone add-on.
- `LC_Voyage_2026-11-03.json` — previous canonical LC source snapshot for comparison.

## Validation and compatibility

- Corrected bundled export: **206 trigger definitions**, **198/198 nonempty JavaScript trigger scripts statically parse**, including **6 Groups triggers**.
- Smoke-tested `sys_lc_quest_summary_command` with an empty quest ledger: returns the expected out-of-world `ACTIVE QUESTS` summary and correctly displays “host world's quest wiring.”
- The full bundle carries **200 non-Group triggers**, with a separate command pre-router, and lacks the modular LC core's five NPC-competence triggers. It is therefore **not a drop-in replacement** for the current `Living_Continuity.json`; do not install it on top of both LC and the Groups add-on.
- The existing standalone Groups version intentionally retains its defensive evidence-source handling and flexible command parser. The full export did not independently justify replacing those scripts.
- Added a Python/Node regression test for every bundled trigger's JavaScript syntax, the quest-summary output, and the distinct standalone/core inventories.
- **No in-game Voyage runtime validation was performed.** Static syntax and smoke checks cannot certify interaction with arbitrary host worlds.
